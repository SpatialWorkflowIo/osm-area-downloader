## v0.1.0 - First Public Release

### Highlights
- Beginner-friendly CLI to download OpenStreetMap features by place name (`--place`) or bounding box (`--bbox`).
- Clean output to GeoJSON by default and optional GeoPackage export (`--format gpkg`).
- New Overpass presets with `--preset`: `all`, `roads`, `buildings`, `pois`.
- GitHub Actions CI added for push/PR with `pytest` and enforced 100% coverage gate.

### Usage examples
```bash
python -m osm_area_downloader --place "Lisbon" --output lisbon.geojson
python -m osm_area_downloader --place "Berlin" --preset roads --output berlin-roads.geojson
```

### Quality
- Test suite currently passes with 100% coverage.
